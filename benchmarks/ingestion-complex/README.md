# 复杂资料独立质量集 v1

背景见 [background.md](background.md)，指标、执行命令和结果见 [质量基线指南](../../docs/complex-document-quality.md)。此前的业务解析和分块语料保留不变。

| 类别             | 输入                 | 开发 / 保留 | 特别核对                         |
| ---------------- | -------------------- | ----------- | -------------------------------- |
| flowchart        | PNG                  | 1 / 1       | 合格与不合格箭头方向，分支交换   |
| chart            | PNG                  | 1 / 1       | 横轴与百分比归属、样本量未知     |
| screenshot       | PNG                  | 1 / 1       | 负金额、零、未批准/已驳回        |
| scanned-table    | 图像型 PDF           | 1 / 1       | 轻微倾斜、表头跨列、空白不等于零 |
| cross-page-table | 两页文本 PDF         | 1 / 1       | 续表、重复表头、列序变化、来源页 |
| multicolumn      | 文本 PDF             | 1 / 1       | 完整左栏后右栏、否定与许可范围   |
| formula-image    | 文字与光栅图混排 PDF | 1 / 1       | 公式符号与单位、图中对象及连接   |

- 输入源：`layouts.json`，schema `complex-layout-v1`。
- 独立标准答案：`annotations.json`，schema `complex-gold-v1`，无模型评分或解析输出反向标注。
- 生成清单：生成器输出 `manifest.json`，记录每份文件、标注、绘图源、生成器、字体和依赖摘要；二进制与预览留在忽略的 `reports/ingestion-complex/`。
- 变更历史：2026-11-24 创建 v1；首次冻结结果和暴露记录见 [基线](../../docs/baselines/complex-document-quality-2026-11-24.json)。修改任意标注或字节即形成新清单；不覆盖旧报告。
- 保留集：只用于独立诊断；本轮原生解析已观察 4 个 PDF 保留样本，之后属于已暴露回归样本。另 3 个 PNG 尚未进行真实模型推理，但均经作者版面检查；不声称严格盲测。后续根据此报告调参后，需新增样本验证泛化。

布局、标注与评分有意分离。不要向解析器传入标准答案，不要用 mock 的通过结果填充模型质量报告，不要为了提高数字而在固定清单中改答案。

2026-11-26 追加 `ocr-table-cases.json`，独立生成两份带轻微倾斜的图像型 PDF，覆盖不同设备、单位、列顺序、中间/末列空值和否定结论。生成命令、首次暴露及与旧版的同输出对照见 [OCR 表格报告](../../docs/ocr-table-quality-report.md)。这两份资料首次推理后同样属于已暴露回归样本；不覆盖原来的 14 份固定输入和标注。
