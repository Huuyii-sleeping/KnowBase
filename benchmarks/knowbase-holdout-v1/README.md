# 新来源合成留出评测

这份数据在既有检索方案选定之后新建，配置和门槛先冻结，不根据本数据的检索得分调参。40 份新文档、8 个新主题、80 道新题，其中 64 正例、16 无答案题；旧数据不复用。主题为湿地声学、天文馆观测、种质冷链、舞台吊杆、古籍阅览、救援通信、陶瓷试烧与珊瑚潜调。

每主题覆盖精确标识、口语表达、否定条件、数值边界、角色、标题章节、跨文档及跨 Chunk 八种正例，另两道无答案题。每个金标准均为正文中的逐字证据。主手册含交班札记以形成较长阅读上下文；札记使用重复结构，80 题按八个主题聚类，不是 80 个统计独立观测。

“留出”指相对于此前调参的数据分离。仍由同一助手在了解旧实验后编写，不是独立作者、真实用户或人工盲测；可能受既有失败类型启发，文风与模板相关性仍存在。第一次查看计分后，本数据转为已暴露回归资料，不能继续拿它调参又称未见验收。

配置和通过门槛见 [实验协议](experiments/protocol.json)，文件指纹见 [冻结清单](freeze.json)。固定当前默认 `body + standard + combined + 15:15` 与既有候选 `title-heading + cjk + body-reserve2:1 + 30:15`，各完整运行一次。它比较整体方案，不将变化单独归因为某个变量；不同配置需要独立完整重建索引。所有查询实验关闭，模型、分块、融合、重排不改，业务不部署。

协议与评分契约、题目、原文先提交后运行；不得根据分数调整配置、问题或答案。合并池证据至少 95%、来源完整率至少 95%、全部证据率至少 90%、每正例类别至少 85%，合并不得丢失证据，且候选不能相对默认新增逐证据池损失。最终 Top 5、负例候选与延迟单独报告，不把候选命中当作回答正确。单次合成测量不代表生产验收。

本轮 160 次计分已完成，见[评测报告](experiments/audit.md)。两套方案池证据均为 100%，候选通过预设池门槛，无新增池损失；最终证据均值 50.00%→71.09%，但有一条最终证据退步，未部署。两次实际索引均为 64 个原始 Chunk，数据与配置没有根据结果改变。
