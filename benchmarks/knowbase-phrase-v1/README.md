# 标识符与短语诊断样本

16 篇短文、8 道正例与 2 道无答案题，均由助手合成并已暴露，仅用于诊断。已有 v3 语料不修改；本样本单独建索引，内部基线与实验组共享同一索引。

覆盖字段值、相近错误码、路径标点碰撞、表名、明确引用的业务短语、否定约束、大小写碰撞及一题不触发的中文控制题。问题只询问明确命名的对象，各题在这个封闭的 16 文档集合内标出完整相关来源；这只是合成样本的严格对象相关性，不能推广为真实用户的相关性标注。`/api/v1/tasks/retry` 与 `/api/v1/tasks-retry`、`currentGeneration` 与 `currentgeneration` 用来揭示分词后短语匹配的边界，不假定一定能分开。

冻结矩阵与文件指纹见 [实验协议](../knowbase-recall-v3/experiments/phrase-match-protocol.json)。相同模型、索引字段、分块和预算下运行三模式、两遍，模式交替；不根据看到的分数修改样本。
