# 召回逐阶段诊断集 v2

此集合保留 v1 的 14 篇文档原文与 40 道开发题，增加 120 篇模拟业务干扰资料和 40 道新的验证措辞题，共 134 篇、80 题。干扰文档由 20 类业务 × 6 类流程模板构成，覆盖相似的上传、审核、列表、权限、异常和归档词汇；不代表真实客户语料。文件中的业务数字和规则均为虚构。

验证题与开发题使用同一组事实和来源，由同一开发助手编写，因此只能算冻结的新措辞验证，不是独立盲测。所有文档、问题、原文证据和 split 在本轮测量前冻结。开发组用于选择召回预算和编码方式，验证组仅在方案选择后评估；没有使用用户私有文档。

召回验收范围、预设阈值和预算选择规则在 `protocol.json`。阈值是本轮工程验证目标，不是已达到的结果，也不是生产 SLO。原始 14 篇和 v1 问题保持不变，v1 基线仍然独立保留。

运行指南和诊断边界见 `docs/evaluation.md` 的召回层诊断部分。索引前只上传 docs/ 内的 Markdown，不上传问题、标准答案、证据、协议和报告。

测量后的选择冻结于 `selection.json`；实测结论与失败样本见 [实验报告](experiments/recall-audit-v2.md)。数据集事实与验收协议保持原样，实验结果不会反向改写题目。
