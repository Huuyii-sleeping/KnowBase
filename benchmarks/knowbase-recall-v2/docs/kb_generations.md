# KnowBase 索引批次与可见性

version 是文档的业务修订号，generation 是一次索引构建的唯一批次号。同一个文档版本可以多次重建，每次得到不同的 generation。

PostgreSQL 的 kh_index_head 按 document_id 和 pipeline 保存当前可见 generation。三条管线分别维护各自的指针。

任务先检查文档仍然发布且版本匹配，再完整写入独立批次。激活前再次锁住文档，核对状态、version 和 content_id，符合条件才切换可见指针。

查询只使用当前已发布修订对应的有效 generation。旧版本任务即使较晚完成也无法覆盖新版，暂存或部分写入的批次不会被查询使用。

同版本重建期间，原来的完整批次继续可见；新批次失败只清理本次构建。全文、向量、图谱独立激活，不保证同时就绪。

旧批次当前暂时保留，尚未自动回收。安全回收需要宽限期以及对在途查询、构建任务和激活操作的协调。
