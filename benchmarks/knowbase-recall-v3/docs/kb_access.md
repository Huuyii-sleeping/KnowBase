# KnowBase 文档访问控制

系统角色为 ADMIN 和 MEMBER。文档的可见性为 PRIVATE、TEAM 或 PUBLIC。

管理员可以查看所有文档。普通成员可以查看自己上传的文档、已发布的公开文档，以及文档团队与自己团队匹配的已发布团队文档。显式 userIds 白名单也可以授权。

未发布的草稿、待审核和驳回文档，仅上传者和管理员可以查看。旧记录或空权限配置默认按 PRIVATE 处理。

关键词检索、语义检索、图谱路径和对象文件代理都使用相同的文档权限规则。权限过滤发生在候选检索阶段，避免无权访问的索引占据 TopK。

读取文档不代表可以修改。只有上传者或管理员可以编辑文档；审核操作要求管理员角色。
