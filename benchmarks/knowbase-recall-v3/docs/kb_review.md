# KnowBase 审核发布流程

业务状态的正常转换为 DRAFT → PENDING_REVIEW → PUBLISHED。驳回时变为 REJECTED，修改后可以再次提交审核。

只有 parseStatus=READY 的草稿或驳回文档才能提交审核。管理员负责审核通过或驳回，普通成员不能审核发布文档。驳回必须填写原因。

审核通过后才触发三条索引任务，分别交给全文检索、向量检索和知识图谱管线异步处理。HTTP 发布成功表示发布状态和任务已经持久化，不表示三路索引已经全部就绪。

修改正文或有意义的标题、标签、分类、权限等元数据会增加文档修订号，并把业务状态重置为 DRAFT。没有实际变化的元数据更新不会增加修订号。

修改正文会创建新的正文记录并更新 content_id，避免直接覆盖旧正文。仅修改元数据时可以继续引用原来的正文记录。
