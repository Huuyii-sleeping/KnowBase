# KnowBase 全文与混合检索

全文检索使用 Elasticsearch 的 kh_document，支持标题、正文、标签、分类和团队字段，提供正文高亮以及分类、团队、标签过滤。

GET /api/v1/search/documents 是关键词检索接口。POST /api/v1/search/semantic 是语义检索接口。POST /api/v1/search/hybrid 是混合检索接口。

混合检索并行执行关键词和向量召回，合并同一文档的结果来源，再执行规则重排。当前重排使用语义得分、关键词得分、词语覆盖率和双路命中奖励，不是独立的神经网络重排模型。

规则重排最多保留每篇文档 2 个候选 Chunk，默认上下文字符预算为 6000。关键词候选如果没有正文，只包含文档元数据，不能直接作为 AI 回答的正文证据。

索引存在只说明数据可被查找，不保证相关内容一定排在前面；需要用固定问题集测量召回和排名。
