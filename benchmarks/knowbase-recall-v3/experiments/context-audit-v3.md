## 冻结设计与计分

158 篇文档、224 题、每种模式 220 个 Chunk；三种模式各 10:10 / 15:15 / 30:10，共 224 × 3 × 3 = **2016 次计分 IPC 请求**，另有不计分预热及 HTTP 路径一致性抽查。开发 96 题、旧回归 80 题、已暴露验证 48 题分别报告。正样本共 180 道，负样本 44 道不混入证据召回分母。

[冻结协议](context-protocol.json) 在首轮运行前提交于 4549a3f。模型固定 nomic-embed-text / plain，关键词 CJK，分块 1000/150，最终 Top 5 及原重排规则不变；每种模式重新上传、发布、建立全新隔离索引。对照脚本核对三轮的所有语料/题目/协议 SHA-256、模型 digest，以及按来源文件和 Chunk 序号排列的全部原始正文完全一致。

检索辅助文本单独写入 retrieval_text，并用于 Embedding；关键词查询其 CJK 多字段。content、引用、路由返回和证据计分只使用原文，不因标题命中就算答案证据命中。标题和章节路径完全来自元数据/源文，不用模型生成。路径按 Chunk 起点继承，块内已有标题保留在原正文；这不是全面的 Markdown AST 或语义父子分块。

## 可复查边界与下一步
