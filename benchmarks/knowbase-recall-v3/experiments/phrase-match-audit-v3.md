# 标识符与短语优先匹配对照

不采用本轮短语加权规则，保持 off。两套题、三模式、两遍共 **1,404 次计分**，没有新增池证据或最终 Top 5 证据，关键词前 5 条的证据召回也没有提升；两道旧题的关键词排名还稳定退步。结论只针对本次冻结规则，不把候选分数变大当作召回改善。

## 测试方法

[冻结协议](phrase-match-protocol.json)及实现先提交为 `82032f3`，所有测量均使用该干净提交。[结果 JSON](phrase-match-results.json)保留指标、逐证据比较、排名退步、控制组与分词探查；[决策 JSON](phrase-match-decision.json)保留不采用理由和验证范围。

- 现有 v3：158 文档、220 原始 Chunk、224 题；每模式两遍，共 1,344 次。
- [专门样本](../../knowbase-phrase-v1/README.md)：16 文档、16 原始 Chunk、10 题，其中 8 正例、2 无答案题；每模式两遍，共 60 次。
- 三模式：off；identifiers；identifiers-phrases。现有题分别触发 0/46/58 题，专门样本触发 0/7/9 题。

每份语料只建一次索引，所有模式和两遍共用文档 ID、generation 与原文快照。按题轮换模式顺序，第二遍反转顺序；逐模式/逐遍保存完整 Trace。固定 nomic-embed-text、plain、CJK、标题章节、正文保护 2:1、关键词 30 / 向量 15、原始读取上限 90/45、最终 Top 5；多意图和降噪关闭。模型摘要和语料指纹已核对一致。

实验只从原问题提取有结构的 ASCII 标识符、驼峰名称、大写缩写以及明确引用的短语，最多四项；同一字段增加 slop=0、boost=2 的可选 `match_phrase`。原来的普通匹配仍必须命中，generation 过滤、权限/发布/版本复查、实际正文返回均复用现有实现。语义查询、索引内容、分块、跨路融合、重排和业务默认不改。没有根据看到的答案补业务词。

计分阶段每题仍是正文关键词、上下文关键词和向量三次索引搜索，按调用计划推算共 4,212 次；query embedding 为 1,404 次。额外短语增加单次查询复杂度，不能据相同请求数宣称成本或生产延迟相同。预热、建索引、分词探查和 HTTP 抽查不计入 1,404 次计分。HTTP 抽查仅验证现行业务原问题 15:15 路径，实验没有公开接口。

本轮控制组稳定：两遍 off 的候选与分数完全一致；所有模式的向量候选与分数均等于同遍 off；未触发的关键词查询也完全一致。现有题中两实验模式分别有 46/58 题候选次序或分数变化，说明加权实际执行了，收益仍为零。这也避免了上一轮独立重建索引波动造成的归因混淆。

## 专门样本与精确匹配边界

8 道正例在基线已全部排第 1，三模式两遍均如此，没有测到增益。基线本身很强，小样本存在明显上限，不能据此宣称所有标识符优化都无效。

封闭的 16 文档集合为每题明确标出完整相关来源，正例严格来源 Precision@1 为 100%、@3 为 33.33%、@5 为 20%，三模式都相同；这里按固定 K 作分母，只有一篇正确来源，返回不足 K 也不缩小分母。这是合成样本的明确对象相关性，不推广为 v3 的完整 Precision。不存在的错误码、v2 路径两题在三模式下各仍返回 2 条关键词候选，没有减少；没有测试问答拒答。

真实 CJK `_analyze` 探查显示：

| 原始字符串 | 分词结果 | 边界 |
| --- | --- | --- |
| `/api/v1/tasks/retry`、`/api/v1/tasks-retry` | 都为 api / v1 / tasks / retry | 短语位置相同，不能判断路径符号是否相同 |
| `currentGeneration`、`currentgeneration` | 都为 currentgeneration | 大小写信息已经丢失 |
| `parseStatus=READY` | parsestatus / ready | 与冒号形式在本次 analyzer 下不同 |
| `parseStatus:READY` | parsestatus:ready | 符号是否保留要实测，不能一概而论 |
| `kh_document`、`kh.document` | 各保留自身单词 | 当前普通匹配已有区分能力 |

路径和大小写混淆文档仍能进入候选，即使正确文档恰好排名第一，也不能说明实现了字符串完全相等。真正按原文值匹配需要明确的标识字段或原文校验，再单独评测；这超出本轮只修改查询加权的范围，本次没有实现。
