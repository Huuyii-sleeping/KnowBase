# KnowBase 检索评测集 v1

本目录是项目原创的合成开发评测集，与 `ragbench-cn` 外部示例独立。内容由开发助手结合当前源码与架构文档编写，上传审批的当前版/历史版是明确标注的模拟业务规则。没有使用用户私有文档；参考答案和原文证据一起维护，评分不依赖模型裁判。

语料共 14 篇，覆盖文件解析、分层存储、审核、投递、索引批次、删除、访问控制、检索、RAG、图谱、依赖端口，以及当前/归档业务规则和一份主题相近的噪声讨论。存储与投递文档超过当前单块长度，用于检查找到文档但漏掉后续关键段落的情况。

| 题型          | 数量 |
| ------------- | ---: |
| 术语/精确提问 |    8 |
| 换种说法      |    8 |
| 流程与条件    |    6 |
| 参数表        |    4 |
| 多文档证据    |    4 |
| 当前/历史版本 |    4 |
| 跨 Chunk 证据 |    2 |
| 无答案        |    4 |

`manifest.json` 定义完整语料集合。`questions.json` 中的每道可回答题包含标准来源 `gold_docs`、参考答案 `reference_answer` 和逐条原文证据 `evidence`；无答案题没有标准来源。校验器要求每个标准来源均有真实存在的证据原句，并拒绝重复题号、含歧义的来源和不完整标注。

完整语料参与每次实验，包括没有作为任何问题标准来源的相似噪声文档。问题不参与索引；不能把问题、答案或证据标注上传到知识库。

运行方式、指标口径和实验边界见 [评测指南](../../docs/evaluation.md)。后续改变语料、问题或标准答案时，应建立新版本或显式更新版本说明，保留原基线与内容哈希，避免新旧分数失去可比性。
