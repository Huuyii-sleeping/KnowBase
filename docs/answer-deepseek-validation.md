# DeepSeek Flash 真实验证

本文为修改前的 Flash 首轮基线。当前上下文、状态与引用合约及后续结果见[收尾验证](answer-refinement-validation.md)。

2026 年 11 月 22 日，按用户已配置的 `DEEPSEEK_MODEL=deepseek-flash` 与官方 Base URL 调用真实 API。先完成一条最小连通性验证，再执行 76 道固定回归及 24 道冲突题的正反顺序，共 124 次问答。接入配置和运行工作目录见[模型接入](answer-model-provider.md)。本轮没有调用 `deepseek-v4-pro`。

## 方法和范围

复用此前冻结的合成题、检索后候选和期望事实。执行前用当前编译的 `AnswerContextService` 重建上下文，逐题确认提示词与冻结版本完全相同；调用实际 `ChatModelService → DeepSeekChatModelService`、生成服务和来源编号校验。上下文筛选、输入预算、提示词及最多一轮引用修正不变，仅更换生成模型。API 采用非思考模式、1,024 token 输出上限、30 秒期限，两个并发任务运行；无自动重试。

由 Codex 对照冻结题目、原文和实际回答逐题复核主问题、数字条件、适用范围与引用支持。来源编号有效不直接计为事实正确；解释性拒答在未确定未知事实或冲突值时计为语义安全，并另行记录固定拒答格式。沿用历史评分口径：不强求回答题目未问的附加事实。这是已暴露合成集的单轮回归，非独立人工盲测、真实用户验收或完整业务 HTTP 测试，也未重新运行召回和重排。

有答案新增六道正确答案：境外住宿不能免审批、生产资料禁止访问、测试资料允许条件、受控零件审批、防护考核不可被口头许可替代、外币必须专项审批。原来正确的有答案题本轮未退步。无答案题补回一道冲突拒答，但新增两道未来年份题退步，不能只报告总收益。

124 次问答全部调用完成，没有异常、超时或引用格式重试，每题均有实际模型调用。本轮 76 题流程 P50/P95 为 0.75/1.68 秒，48 次冲突对照为 0.63/2.03 秒。历史本地基线采用不同时间、硬件和运行方式，不据此宣称严格的速度提升比例。这里不是持续负载容量测试，未采集账单费用，也未验证长答案超过当前输出预算时的表现。

## 仍然存在的问题

- **现行证据未进入上下文**：`dev-10`、`hold-10` 仍未完整回答现行押金。词面筛选保留了旧版块却漏掉现行块，模型正确承认未得到现行金额；更强模型不能回答未交给它的资料。这是上下文构建问题。
- **未来适用不确定性**：`dev-17`、`hold-17` 将只标明 2026 年生效的标准断言为 2028/2029 年标准。按冻结题意应拒绝保证未来值，保留两项失败；原文未给终止日期，题目对“未来预测”与“现行规则持续适用”的区分也有歧义，不能用这两题证明广泛幻觉率。后续应在新增题中明确预测意图、有效期或复核要求，不修改本轮标注来消除退步。
- **拒答格式与业务状态**：语义安全不等于遵循固定拒答模板。76 题的 28 次语义安全拒答中只有 24 次输出标准拒答；冲突对照的 16 次中只有 7 次使用标准拒答。其余给出了来源支持的不足/冲突说明，没有擅自选择值，但当前生成服务将这些带有效引用的说明标记为 `answered`。本轮未用字符串包含规则猜测拒答，也未改变状态或前端展示；若产品依赖状态分流，应单独设计结构化输出合约并评测。

本轮表明用户选择的 Flash 对这些条件与冲突题明显优于历史本地模型，但尚未消除上下文遗漏、未来适用与拒答状态问题；不把样本中的引用正确率当作在线事实保证。运行时继续使用用户配置，不擅自替换为 Pro。
