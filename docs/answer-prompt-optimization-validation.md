# 提示词三项优化对照

2026-11-23，固定现有 DeepSeek Flash、生成参数、引用合约与候选内容，分别测试消息分层、超长证据补充、逐项解释提示。只采用得到实际收益的方向；不保留生产实验开关，不调整召回、重排或模型。

## 冻结样本与对照

首轮 48 题：21 道资料指令隔离题、14 道长来源题、13 道解释题，每项单独与现行版本比较。长来源包含答案在首/中/尾、同节例外、分离材料、同义表达、表格、无答案以及不可拆分单段容量边界。随后先冻结 10 道反例：4 道远处隐含例外、4 道子章节例外、2 道完整候选名额竞争。

合计执行首轮 96、反例 20、修订后 74 次对照流程。无上下文时不调用模型，流程执行数不是 API 请求数。使用真实生成适配器、JSON 解析和原文引用校验；固定候选替代检索，不声称本轮重新完成了上传、索引和 HTTP 链路验收。

样本均由同一助手合成并在推理前冻结，反例也单独冻结；不能当作独立人工盲测或真实业务准确率。问题、正文和标签不随结果改写，完整性、状态合约与引用逐字真实性分别判断。

## 采用与放弃

| 方向                     | 对照结果                                                                            | 决定                         |
| ------------------------ | ----------------------------------------------------------------------------------- | ---------------------------- |
| 系统规则与用户资料分消息 | 21 题基线全部通过，分层后 20/21；含伪造指令的一题新增误拒                           | 放弃本轮分层实现             |
| 逐项解释提示             | 两种提示位置均未修复原有 PRIVATE / TEAM / PUBLIC 含义遗漏；6 道显式定义题两边均完整 | 放弃额外提示                 |
| 超长来源按节补充         | 原 11 道有答案题由 0/11 到 11/11，子节例外另补回 4/4；远处隐含例外仍 0/4            | 采用，保留容量与条件覆盖边界 |

消息分层结果只说明本轮实现没有收益，不能推出消息角色本身无用。解释组另有 6 道“已知定义＋未提供过期时间”混合题：两边都给出真实的“未规定”说明，却返回 `answered`，不符合现有“缺少必答事实应 insufficient”合约；没有将这些题计作完整通过，也没有改金标掩盖问题。

长来源初版直接把选节结果放进候选列表，导致 2 道竞争题挤掉完整材料并误拒。修订后先保留所有正常入选来源，剩余名额才补充超长来源，两题恢复到完整回答；不是用新收益抵消已知退步。最终长来源组中，19 道原本整体放不下的有答案题补回 15 道，另外 2 道普通完整候选控制题保持完整；2 道实际缺少事实题继续拒答，1 道不可拆分超长单段仍因容量不足拒答。后者有答案，不能算作正确无答案识别。

实现、预算及原文位置合约统一见[上下文与引用设计](answer-context.md)，不将实验用例、批量脚本和原始模型报告加入业务代码。

## 采用版本回归

通过实际 `AnswerService → AnswerContextService → AnswerGenerationService → AnswerCitationService` 回放原有 248 题和本轮 58 题，共 306 次。检索仅替换为冻结结果，生成仍调用真实 API，未使用实验提示或请求覆盖。306 次执行没有调用失败，返回 204 次回答、102 次拒答；这些是输出状态数量，不是正确率。

原有 248 题的上下文列表全部保持一致，回答/拒答状态仍为 156/92；核对变化答案未发现新增事实或必要条件遗漏，原有权限枚举解释不完整继续单列。新题得到与修订对照一致的长来源补回效果，同时仍保留上述解释与混合子问失败，没有将它们算作通过。

400 条返回引句均可在其编号来源中逐字找到；所有截取来源的 `contentRange` 可还原为原候选的连续子串，引用与上下文范围一致，完整输入含修正指令的预算检查均通过。这证明来源真实和位置一致，不能替代语义支持或条件完整性判断。

代码验证：API 73 个测试文件、388 项测试通过；前端 11 项测试通过，API 与前端构建通过，评测工具 5 项测试通过，4 份 Compose 配置静态验证通过。新测试覆盖原文偏移、跨节引用隔离、完整来源优先、整体字节预算、无法拆分与无匹配时的回退。实验文件保留在忽略的 `reports/answer-prompt-study/2026-11-23-r1/`，没有提交、合并或重启主工作区。

## 尚未解决

- 词面选节不能保证远处隐含例外被保留；本次 4 道反例安全拒答，但不能保证其他来源都能避免遗漏。
- 原有权限枚举解释仍可能只列名称，缺少实际可见范围；额外通用解释指令无收益。
- 混合已知与未知子问仍可能返回部分事实及“未规定”说明，违反当前完整回答状态合约。该问题需要独立处理，不以逐字引用通过代替回答完整。
