# 问答证据与来源合约

`AnswerRetrievalService` 获取已复查的文本和图谱候选，`AnswerGroundingService` 做词语支持筛选与排序，纯函数 `fitAnswerContexts` 负责有界的完整片段选择。当前分支默认最多5块、总正文6000 UTF-16字符，保留既有首块超长例外；同一文档相同正文去重，不切断段落，不合并来源身份。

`AnswerPromptService` 按最终上下文顺序分配 S1、S2 等临时编号。模型必须自行标注来源；编号只属于本次上下文，不允许指向未传入模型的片段。多个事实应分别引用支持它们的片段；历史规则不得被描述为现行规则。

`normalizeCitationMarkers` 只规范明确的分组形式，如 `[S1, S2]` 转为 `[S1][S2]`，不补编号、不猜来源。`AnswerCitationService` 验证所有编号都在本次范围内，并将其映射回原始 documentId/chunkId；缺失或非法来源时不输出看似已核实的回答。固定拒答句前后的来源标记都会被移除，最终返回空引用及空上下文。

来源编号合法不代表它支持结论。当前没有用正则或来源文件名猜测语义正确性，也没有自动把未标来源的回答挂到第一块。缺失来源导致拒答是一项可见行为变化，必须同时评估答案覆盖与引用可靠性。

本分支的代码修复和生成验收状态见[答案模型对照](../benchmarks/knowbase-rerank-v2/integration/answer-model-audit.md)。3B/7B 未达到冻结的完整事实与语义引用门槛，因此默认生成模型仍为 qwen2.5:0.5b，BGE 分支仍为 Draft。这不表示旧默认的生成质量已经可靠；候选池证据覆盖、上下文证据覆盖和最终答案准确性必须分别报告。
