## 为什么需要视觉模型

MinerU 的本次部署负责布局、文字和表格提取，关闭其内置图像分析。OCR 可以读出文字，却未必保留文字之间的视觉联系。例如流程框之间的箭头及条件、柱形图的类别与数值、正文中示意图的端点名称。

视觉模型读取 MinerU 裁图或独立图片原件，生成描述、事实、关系和不确定项；结果与 OCR、原图、原生表格独立留存。它并非所有文档的必经步骤：本次多栏文本没有图像证据，不调用 VLM；截图和原生表格的关键事实 OCR 已覆盖，再生成自由描述会增加成本和错误机会。

下面分开报告 OCR 与生成描述，不能把视觉文字算成 OCR 提升。每行开发/保留各一份；表格是按页结构核对，非自由文本中数字共现。

```bash
"$LLAMA_SERVER" \
  -m reports/ingestion-complex/vision-model/Qwen3VL-2B-Instruct-Q4_K_M.gguf \
  --mmproj reports/ingestion-complex/vision-model/mmproj-Qwen3VL-2B-Instruct-Q8_0.gguf \
```
