## 已实测结果：原生 PDF 解析诊断

使用项目实际 `FileParserService` 和 `pdf-parse`，不是 mock；资源上传使用本地内存捕获并保存回读，不连接生产数据库。14 项中 8 个 PDF 完成解析观察，6 个 PNG 为原生路径不支持，标为 unavailable，未给予质量分数。下表每个开发/保留单元格对应一份输入，跨页台账含两页。

| 类别         | 开发集                             | 保留集                            | 观察                                        |
| ------------ | ---------------------------------- | --------------------------------- | ------------------------------------------- |
| 流程图 PNG   | 待真实 OCR/VLM                     | 待真实 OCR/VLM                    | 原生路径不支持，不能记为 0% 或通过          |
| 统计图 PNG   | 待真实 OCR/VLM                     | 待真实 OCR/VLM                    | 数值与类别归属须进一步实测                  |
| 截图 PNG     | 待真实 OCR/VLM                     | 待真实 OCR/VLM                    | 负金额与否定审批状态须进一步实测            |
| 扫描表格     | 关键点 0/3；单元格 0/13            | 关键点 0/3；单元格 0/13           | 无文字提取，原生解析标记需核对、ready=false |
| 跨页台账     | 关键点 2/2；单元格 18/18；整表 2/2 | 关键点 2/2；单元格 0/18；整表 0/2 | 换列后归属失败；两份输入的页来源均 2/2      |
| 双栏通报     | 文字点 8/8；关键点 2/2；顺序 1/1   | 文字点 8/8；关键点 2/2；顺序 1/1  | 当前简单双栏成立，不代表任意多栏资料        |
| 公式与图混排 | 关键点 3/3；文字点 1/3；连接 0/1   | 关键点 3/3；文字点 1/3；连接 0/1  | 公式参数可读，图中两端名称和结构化关系缺失  |

**台账的问题是信息归属，而非数字消失。** 保留集原图列序为 `条件 / 阶段 / 金额（万元）`，原生结果变成两列 `阶段 / 金额（万元） 条件`，例如 `预付 | 48.75 合同生效`。逐字找金额会通过，但页内行列坐标核对失败。该样本保留原状，作为后续定向验证的回归点；本轮没有根据结果修改解析器。

公式页输出 ready=true，也不证明图像完整：公式及数值被读取，嵌入光栅图里的“固定端 / 测量端”没有进入正文，实际捕获的提取资源为零。后续应重点核验真实 MinerU 的原图提取、独立图像证据及 VLM 描述交付，再决定修复位置。

全部 8 个完成观察的 PDF 均通过本地解析 JSON 保存/回读；没有提取图像资源，不能以此宣称图像保存闭环通过。扫描输入没有保存出错误的“已核实数值”。已知相反事实检测为零，仅表示未匹配预设相反短语，**不等于证明没有幻觉**。

同一原生解析器重复运行，8 个可比较 PDF 的所有核对维度增量均为零，6 个 PNG 保持不可比较；这验证了本次诊断计分的重复性，不是质量提升或性能评测。一次运行耗时仅保留在机器报告，不计算吞吐、P95 或提速比例。

## 尚未实测：当前默认 MinerU 与视觉增强

本机没有运行可连接的 MinerU 服务，未提供固定 MinerU 部署修订；没有配置 `VISION_BASE_URL / VISION_MODEL / VISION_MODEL_REVISION`。本地 Ollama 只有文本/Embedding 模型，不能充当真实视觉理解模型。

因此，`mineru-ocr` 与 `mineru-vision` 两份可用性报告各记录 14 项 unavailable、0 项完成，无质量分数；没有模型耗时、token 或成本结论。未安装或下载大模型替代既定服务。工具中的小 fixture/fake 只验证评分、状态、持久化清理和异常处理，不进入质量统计。不能将上表当成 MinerU 的失败分布，或宣称本轮验证了视觉增强有效。
