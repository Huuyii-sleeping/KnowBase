# 前端视觉与交互规范

## 设计方向

Knowbase 是面向团队的知识工作台。采用清爽的浅色界面，让文档、检索依据与知识关系成为页面主体。

- 画布：雾灰 `#F5F7F9`，内容区使用白色。
- 文字：深蓝灰 `#1E2D39`，辅助文字使用灰蓝。
- 主色：蓝绿 `#18777C`，用于主要操作、当前导航与焦点；浅蓝绿用于选中状态。
- 边框：浅灰蓝 `#E0E6EC`；状态色继续区分草稿、待审核、已发布与失败。
- 字体：品牌与英文优先使用本地 Avenir Next，中文回退到系统黑体；代码使用系统等宽字体。无需外部字体服务。
- 页面标题 27–30px，正文 13–14px，辅助信息 11–12px。色彩 token 以 `src/index.css` 为准。

文档库的连接图形对应“文档 → 知识关联 → 问答”，仅为装饰，不展示虚构统计或服务状态。文件类型以彩色文件标识辅助识别，发布状态与解析状态继续独立展示。

## 组件边界

- `AppShell`：导航、全局搜索入口、登录身份及移动导航交互。
- `PageHeader`：页面标题、说明和操作区。
- `EmptyState`：空数据说明及可选的下一步操作。
- `FileSymbol`：文件类型标识；未知类型使用中性样式。
- `ui/icon.tsx`：统一的装饰性线框图标；图标按钮通过按钮本身提供可访问名称。
- `ui/*`：按钮、输入框、表格与 Radix 弹窗等基础交互。

页面继续负责请求、筛选、分页、URL 状态和业务操作；视觉组件不访问 API。沿用 React、Tailwind、Radix，不引入新的 UI 框架。

## 响应式与可访问性

桌面使用固定宽度导航与自适应内容区；窄屏切换为抽屉导航。打开抽屉后限制键盘焦点、锁定背景滚动，支持 Escape 关闭并恢复触发按钮焦点。文档表格在自己的容器内横向滚动，不撑开页面；弹窗限制宽度与高度，内容可滚动。

全局搜索支持 Command/Ctrl + K。文档标题使用真实链接，支持键盘和新标签页访问；状态筛选使用 `aria-pressed`。弹窗提供具名关闭按钮；页面提供跳过导航链接、可见焦点和减少动态效果偏好支持。

## 本地预览与验证

```bash
pnpm --filter @knowbase/web dev --host 127.0.0.1
pnpm --filter @knowbase/web test
pnpm --filter @knowbase/web build
```

访问 `/documents?mock=1` 可使用项目已有的文档与图谱演示数据；该模式在当前浏览器会话保持，`?mock=0` 关闭。问答与检索仍需要真实 API；演示模式不模拟这些接口。审核队列需要管理员登录。

视觉回归应检查桌面与手机宽度下的文档筛选、搜索无结果、文档详情、上传弹窗、导航开关、问答初始状态、图谱查询和登录页。基础展示契约由 `components/presentation.spec.tsx` 覆盖，业务测试保留在对应模块。

## 知识图谱关系网络

采用现有的 [AntV G6](https://g6.antv.antgroup.com/) 作为本地图形引擎，无需把文档或图谱数据发送到第三方网站。G6 已具备力导向布局、节点拖动、曲线边和视口控制；当前需求无需另加 Cytoscape.js 或 Sigma.js。

默认“关系网络”使用 D3 力导向布局，结合查询节点的径向约束、斥力和碰撞检测，让节点分布在二维空间；“层级视图”使用 Dagre，方便按方向读取链路。圆形节点的完整名称显示在下方，查询实体使用蓝绿实色，其余实体按类别使用浅色；有向曲线上的文字表示关系类型。平行关系分别显示，不合并掉不同的关系名称。

使用 G6 标签避让行为处理重叠，优先保留节点名称和当前路径的关系标签。缩放后重新判断可用空间；完整的关系名称始终可在路径详情中读取。

标签使用独立的 `knowledge-graph-labels.ts` 行为维持屏幕字号，读相机的实际缩放值，兼容滚轮、相对缩放和路径重绘。G6 5.1.1 自带的 `fix-element-size` 把相对缩放事件的倍率当成绝对缩放，会在路径切换后让字号变小，因此此处使用基于其扩展 API 的小型行为。最小缩放允许到 2%，使接口上限的多分支层级图也能完整适配；密集图的全局视图用于总览，细节通过放大和路径侧栏阅读。

画布优先占据页面宽度，路径选择与有序路径详情放在右侧，窄屏下移动至画布下方。用户可缩放、居中、展开画布，或通过键盘选择实体查看来源。路径切换仅更新高亮，保留节点位置与缩放；查询实体、关系拓扑或布局模式变化才重新布局。容器尺寸变化通过 ResizeObserver 重新适配，不依赖窗口 resize 事件。

实现职责：

- `lib/knowledge-graph-data.ts`：合并实体、关系与来源，形成可展示数据。
- `lib/knowledge-graph-presentation.ts`：节点与连线样式、布局参数和拓扑标识。
- `lib/knowledge-graph-renderer.ts`：图形引擎加载、串行更新、视口控制与销毁；通过可注入加载器测试异步竞态和失败清理。
- `lib/knowledge-graph-labels.ts`：缩放与重绘时保持标签的屏幕字号。
- `hooks/use-knowledge-graph.ts`：连接 React 生命周期、容器尺寸和画布状态。
- `components/knowledge-graph-diagram.tsx`：画布工具栏、实体选择和详情展示。
- `components/graph-path-panel.tsx`：路径选择、关系方向和来源跳转。

画布加载失败时保留容器并提供重试。销毁或新请求到来后，旧的异步加载不会再创建画布；已经开始的渲染完成后再清理资源，避免卸载期间销毁冲突。

复杂数据的真实浏览器测试入口和结果见 [图谱组件验证](graph-validation.md)。
